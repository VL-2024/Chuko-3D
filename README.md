# CHUKO Modern 3D v0.8.20 — hard safety clamp

В 0.8.19 редкие чүкө всё ещё могли проскочить физический периметр на высокой скорости. В 0.8.20 добавлен абсолютный аварийный ограничитель.

## Что изменено

- физический невидимый периметр стал плотнее, выше и чуть ближе;
- ещё сильнее тормозится наружная скорость у края;
- добавлен **emergency clamp**: если чүкө всё-таки проходит внешний радиус, его позиция в следующем кадре возвращается внутрь безопасной области;
- после возврата задаётся небольшая скорость внутрь, без сильного отскока;
- немного снижена максимальная энергия дальнего разлёта.

## Цель

Ни один чүкө не должен исчезать за границей экрана даже в редком высокоскоростном сценарии.
