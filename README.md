# CHUKO Modern 3D v0.8.21 — жёсткое удержание чүкө внутри экрана

В этой версии добавлена не только физическая защита, но и экранная. Если чүкө подходит к видимой границе кадра, он принудительно возвращается внутрь.

## Что изменено

- невидимый периметр стал ещё плотнее и ближе к краю;
- усилено трение поля и страховочного пола;
- разлёт ещё немного компактнее;
- добавлен **screen-space clamp**: если чүкө визуально подходит к краю экрана, он тут же возвращается внутрь;
- аварийный возврат после clamp стал мягче, чтобы не было заметного отскока назад через всё поле.

## Цель

Наконец полностью убрать редкие вылеты чүкө за границы экрана, сохранив живой, но компактный разлёт.
