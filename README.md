# CHUKO Modern 3D v0.8.6 — live tuning panel

Добавлена мобильная панель регулировок для точной подгонки 2D-арта v20.61 и 3D-механики прямо на iPhone.

## Ползунки

**Фон и поле**
- размер поля;
- поле выше/ниже;
- поле влево/вправо;
- масштаб и положение фона.

**Кучка чүкө**
- положение X/Z;
- ширина и глубина кучки.

**3D камера**
- общий видимый размер 3D;
- смещение 3D по X/Z.

**САКА**
- стартовое положение X/Z.

## Важно

- Значения автоматически сохраняются в `localStorage` этого браузера.
- После перезагрузки они восстановятся.
- Кнопка «КОПИРОВАТЬ ПАРАМЕТРЫ» копирует JSON со всеми значениями.
- После того как композиция будет идеально подогнана, эти значения можно зафиксировать в коде и убрать панель.

Механика Havok, разлёт и pooling не менялись.
