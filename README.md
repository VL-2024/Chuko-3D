# CHUKO Modern 3D v0.12.1

Усилена читаемость сценарных конечных позиций и гарантирован контакт САКА с чүкө.

## Конечные точки чүкө
- выбитые чүкө теперь получают точки существенно дальше за белой линией (`metric 1.38–1.52`), чтобы модель гарантированно не соприкасалась с линией;
- оставшиеся внутри распределяются до `metric 0.98`; часть из них может лежать вплотную к белой линии или слегка перекрывать её краем примерно на 15–20% размера;
- точки по-прежнему рассчитываются заранее, до запуска САКА.

## Контакт САКА
- после выбора направления точка падения САКА привязывается к ближайшему реальному чүкө;
- поэтому перед запуском сценарного разлёта САКА должна визуально коснуться как минимум одного чүкө;
- баллистическая дуга сохранена.
