# CHUKO Modern 3D v0.11.2 — visual white-circle scenario fix

На скриншоте v0.11.1 было видно, что ONE показывает `Выбито: 1`, но визуально за белой линией лежит больше одного чүкө. Причина: ограничения сценария всё ещё работали по **мировому радиусу 3D**, а белый круг находится внутри 2D-картинки поля и имеет собственную перспективную эллиптическую форму. Эти две границы не совпадали.

## Что исправлено

- белый круг теперь калиброван непосредственно по `field-realistic.webp`;
- положение каждого чүкө проецируется из Babylon в экранные CSS-координаты;
- далее проверяется относительно **видимого эллипса белой линии на картинке**;
- нецелевые чүкө удерживаются с заметным запасом внутри белой линии;
- целевые считаются OUT только когда их центр явно вышел за видимую белую линию;
- в конце раунда целевые фиксируются явно снаружи, нецелевые — явно внутри.

## Что теперь считается «выбито»

В сценарном режиме выбито — это чүкө, которому сценарий присвоил состояние `OUT` и который визуально размещён **явно за белой игровой линией**. Простое касание белой линии или выступающий край модели не считается выбитым.

Ожидаемое визуальное соответствие:
- ZERO: 0 снаружи;
- ONE: 1 снаружи;
- TWO: 2;
- THREE: 3;
- FOUR: 4;
- FIVE: 5;
- FIVE_KHAN: 5 обычных + ХАН.
