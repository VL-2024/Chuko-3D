# CHUKO Modern 3D v0.4.2

Точная настройка мобильного прицеливания для Babylon.js + Havok. База механики — ЧҮКӨ v20.61. LMS пока не подключён.

## Что исправлено в v0.4.2

- Исправлено зеркальное горизонтальное управление: **потянул САКА пальцем влево → точка падения уходит вправо**, как у рогатки.
- Точка падения больше не вычисляется старой схемой «угол луча + сила». Теперь движение пальца напрямую перемещает прицел внутри допустимой 2D-зоны кучки.
- Учтён разворот 3D-камеры: направление screen-right определяется по реальной проекции Babylon, а не через мировую ось X.
- Вертикальное движение тоже работает по принципу рогатки: pull вниз переносит точку глубже через кучку.
- Длина натяжения по-прежнему задаёт силу броска.
- Для ручного броска случайная погрешность отключена: **жёлтое кольцо и фактическая баллистическая цель совпадают**.
- Автобросок по кнопке по-прежнему может иметь небольшую вариативность.
- FPS-панель и Havok-физика сохранены без изменений.

## Проверка на iPhone

1. Потянуть САКА влево — кольцо должно двигаться вправо.
2. Потянуть вправо — кольцо должно двигаться влево.
3. Двигать палец по диагонали — кольцо должно плавно проходить по зоне кучки без скачков.
4. После отпускания САКА должна падать туда, куда показывало кольцо.
5. Убедиться, что FPS остаётся около 60.

## Пока не делаем

- LMS и реальные билеты;
- сценарное выбивание заданного количества чүкө;
- финальные GLB/GLTF-модели;
- звук, музыка, результат, автоигра.
