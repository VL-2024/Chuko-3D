# ЧҮКӨ Modern 3D — prototype v0.1

Первый мобильный 3D-прототип новой версии ЧҮКӨ.

## Что сделано

- Babylon.js 9.25.0.
- Havok Physics for Web.
- Круглое игровое поле.
- 12 простых 3D-чүкө.
- Отдельный золотой ХАН в кучке.
- Крупная синяя САКА.
- Бросок САКА рассчитывается как настоящая баллистическая траектория: Havok поднимает САКА по дуге, затем она падает сверху в район кучки и физически сталкивается с объектами.
- Физический разлёт без сценариев LMS.
- FPS / frame time / количество physics bodies / render scale на экране.
- Mobile-first render scaling: DPR ограничен; при устойчиво низком FPS прототип автоматически переходит на 1x rendering.
- Кнопки «Бросить САКА» и «Сброс»; бросок также запускается тапом по верхней части игрового поля.

## Что сознательно НЕ сделано на этом этапе

- LMS / API / реальные билеты.
- Сценарии выигрыша ZERO/ONE/TWO/FIVE/FIVE_KHAN.
- Гарантированный выброс заданного числа чүкө — сейчас это чистый физический тест Havok.
- Финальные 3D-модели чүкө, ХАН и САКА.
- Звуки, музыка, выигрышная UI-анимация, автоигра.
- Защита/сборка production bundle.

## Связь с v20.61

Из v20.61 сохранены базовые ориентиры механики: 12 чүкө, отдельный ХАН, САКА крупнее обычных фигур, компактная кучка и главное — бросок должен восприниматься как падение сверху в кучку. В v20.61 дуга была визуализирована поверх 2D-физики; здесь дуга выполняется самой 3D-физикой Havok.

## Запуск

Это статический прототип. Из-за WASM Havok и загрузки CDN лучше запускать через HTTP-сервер, а не двойным кликом `file://`.

Например:

```bash
python -m http.server 8080
```

После этого открыть `http://localhost:8080`.

Для теста на смартфоне компьютер и телефон должны быть в одной сети; открыть IP компьютера с портом 8080.
