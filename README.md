# CHUKO Modern 3D v0.9.10 — dust visibility + SAKA edge safety

Исправлены три замечания.

## 1. Высота чүкө
- `chukoModelY` теперь по умолчанию **-0.16**.

## 2. Пыль
- сделана существенно заметнее;
- частицы светлее, чуть крупнее и живут дольше;
- выброс идёт локально вверх и в стороны;
- никакого кругового кольца нет.

## 3. САКА у дальнего края ковра
- добавлено мягкое торможение после фактического контакта;
- если САКА всё же достигает края или начинает проваливаться, она возвращается на безопасную часть поля;
- ограничение включается только **после удара**, поэтому баллистический полёт не затрагивается.

Дополнительно исправлен visual lift САКА: в предыдущей версии условие не срабатывало корректно, теперь GLB действительно приподнимается относительно физического proxy.
