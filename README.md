# CHUKO Modern 3D v0.7 — field + Kyrgyz environment

Визуальный этап после стабильной v0.6.1 (60 FPS на iPhone). Механика броска, управление, Havok-физика, pooling/reset и параметры разлёта оставлены без изменений.

## Что добавлено

- Новое круглое игровое поле: тёмная база, тёплая игровая поверхность, бордовый кант и золотое кольцо.
- Лёгкий кыргызский орнамент по периметру поля через Babylon instances — без дополнительных physics bodies.
- Дальний горный горизонт Кыргызстана из трёх low-poly слоёв.
- Тёплое низкое солнце и более кинематографичный свет.
- Небо — маленькая процедурная gradient texture, без тяжёлого HDR/skybox.
- Линейный туман для мягкого отделения гор от игрового поля.
- Все декоративные объекты статичны, без физики и без теней; часть world matrices/materials заморожена ради мобильного FPS.

## Что не менялось

- 12 чүкө + ХАН + САКА.
- Точное управление точкой падения.
- Баллистическая дуга сверху.
- Havok CONVEX_HULL colliders.
- Усиленный физический разлёт v0.5/v0.6.
- Pooling/reset v0.6.1.
- LMS не подключён.

## Проверка на iPhone

1. Убедиться, что сверху показано `v0.7`.
2. Посмотреть FPS до броска, во время удара и при «ЕЩЁ БРОСОК».
3. Оценить, не мешают ли горы/орнамент чтению кучки и траектории.
4. Цель: около 60 FPS; короткая единичная просадка допустима, но устойчивого падения быть не должно.

Если Safari показывает старую версию, открыть URL с `?v=07`.
