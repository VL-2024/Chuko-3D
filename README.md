# CHUKO Modern 3D v0.8 — visual upgrade from v20.61 references

Этот билд сохраняет стабильную механику v0.6.1/v0.7 (Babylon.js + Havok, pooling/reset, бросок САКА по дуге, ручное прицеливание и физический разлёт), но поднимает сцену из схематичного вида к полу-реалистичному визуалу на основе референсов из ЧҮКӨ v20.61.

## Что сделано

- Добавлен фото-бэкдроп на основе `background-realistic.webp` из v20.61: горы Кыргызстана, тёплый закат, мягкая атмосферная перспектива.
- Небо стало теплее и ближе к настроению v20.61.
- Поле полностью переделано визуально:
  - тёмный деревянно-кожаный цоколь;
  - глубокая синяя игровая поверхность;
  - процедурная текстура с мягким градиентом, внутренним кругом и орнаментальными метками;
  - более премиальный золотой кант;
  - декоративные камешки вокруг поля.
- Внешняя среда стала богаче, но остаётся лёгкой для iPhone: все новые декоративные элементы статичны и без физики.

## Что не менялось

- 12 чүкө + ХАН + САКА.
- Havok CONVEX_HULL colliders.
- Точное прицеливание и управление по принципу рогатки.
- Баллистическая дуга.
- Усиленный разлёт v0.5/v0.6.
- Pooling/reset без пересоздания физических тел.
- LMS не подключён.

## Что проверить

1. На iPhone вверху должна быть версия `v0.8`.
2. Сравнить общий вид сцены с v0.7: поле, горы, свет, атмосфера.
3. Проверить FPS до броска, в момент удара и при «ЕЩЁ БРОСОК».
4. Оценить, не мешает ли фото-бэкдроп читаемости траектории и кучки.

Если Safari показывает старую версию, открыть URL с `?v=08`.
