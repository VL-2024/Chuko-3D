# CHUKO Modern 3D v0.9.10 — polish update

В этой версии внесены правки по последним замечаниям пользователя.

## Что изменено

- **пыль убрана полностью**;
- расширен диапазон регулировки **кучки чүкө вперёд/назад** в минус по `pileZ` (теперь минимум **-1.80** вместо **-1.00**);
- применены новые стартовые настройки сцены и моделей;
- **ХАН** и **САКА** визуально осветлены по сравнению с предыдущей версией;
- новые настройки применяются сразу, потому что ключ локального хранения обновлён.
