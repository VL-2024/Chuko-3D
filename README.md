# CHUKO Modern 3D v0.10.3

Аварийный bugfix v0.10.2.

Причина поломки:
- в v0.10.2 функция удержания САКА внутри белого круга использовала переменную `sakaClampPending`;
- сама переменная не была объявлена;
- после начала броска возникал JavaScript `ReferenceError`, из-за чего останавливался render loop;
- поэтому САКА не летела, а после этого интерфейс казался неработающим.

Исправление:
- добавлено `let sakaClampPending = false;`;
- больше никаких изменений физики, прицеливания, номиналов или игрового цикла не вносилось;
- localStorage key сохранён, поэтому текущие настройки пользователя не сбрасываются.
