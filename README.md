# CHUKO Modern 3D v0.8.13 — release by real contact proximity

Исправление v0.8.12: кучка больше не ждёт слишком позднего условия, из-за которого Havok иногда не успевал дать разлёт.

## Что изменено

- Момент разблокировки теперь определяется по **реальному 3D-расстоянию САКА до ближайшего чүкө/ХАНА**.
- Есть резервная проверка по точке попадания, чтобы срабатывание не потерялось при ударе в промежуток между чүкө.
- Кучка остаётся STATIC почти весь полёт и становится DYNAMIC буквально перед контактом.
- В этот же кадр применяется умеренный impact boost.
- Разлёт немного смягчён относительно ранних слишком сильных версий.

Ожидаемое поведение: до удара кучка визуально неподвижна; в момент контакта происходит нормальный физический разлёт.
