# CHUKO Modern 3D v0.8.2 — max visual similarity to v20.61

Эта версия специально перестраивает экран так, чтобы он был визуально максимально близок к ЧҮКӨ v20.61. Фон и поле используются напрямую из загруженных файлов `background-realistic.webp` и `field-realistic.webp`.

## Главное

- `background-realistic.webp` используется как основной экранный backplate почти 1-в-1.
- `field-realistic.webp` используется как основное визуальное поле почти 1-в-1.
- Убраны лишние схематичные элементы предыдущих версий: большая плоскость земли, декоративные кольца и посторонний стиль поля.
- 3D-механика (чүкө, ХАН, САКА, бросок, траектория, Havok, pooling/reset) сохранена.

## Что проверить

1. Насколько экран стал похож на v20.61 по общему ощущению.
2. Совпадают ли фон, поле, композиция и цвет.
3. Не мешают ли 3D-объекты читаемости поля.
4. FPS до броска, при ударе и после `ЕЩЁ БРОСОК`.
