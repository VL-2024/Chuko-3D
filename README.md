# CHUKO Modern 3D v0.9.9 — visible dust and SAKA anti-clipping lift

Исправил два замечания по v0.9.8.

## Что изменено

### 1) Пыль стала заметнее
- увеличено количество частиц;
- слегка увеличен размер частиц;
- повышена видимость и плотность;
- пыль стартует чуть выше точки контакта;
- оставлена форма короткого локального облачка, без расходящегося кольца.

### 2) САКА иногда проваливалась визуально ниже чүкө
- добавлен небольшой **визуальный lift** для GLB САКА;
- lift применяется только к отображению модели, а не к физическому Havok-прокси;
- благодаря этому САКА меньше клиппится и реже оказывается визуально «под» чүкө.

## Что не менялось
- Havok-физика;
- баллистика;
- GLB-модели;
- текущие пользовательские параметры сцены.
