# CHUKO Modern 3D v0.8.22 — стабильная САКА + отдельное ограничение чүкө

В v0.8.21 невидимый физический периметр оказался слишком близко и начал влиять на САКА: она могла цеплять стенку, уходить вбок или кружить.

## Что сделано

- за основу броска возвращена стабильная механика v0.8.19;
- полностью убраны физические стенки вокруг поля;
- САКА больше вообще не участвует в логике ограничения;
- ограничиваются только чүкө и ХАН;
- если чүкө подходит к краю экрана, именно этот объект мягко возвращается внутрь;
- редкие слишком высокие вылеты чүкө дополнительно гасятся.

## Ожидаемый результат

- САКА снова летит по чистой баллистической дуге сверху;
- нет боковых ударов из-за невидимых стен;
- чүкө при этом не должны исчезать за краями экрана;
- FPS должен остаться около 60.
