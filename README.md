# CHUKO Modern 3D v0.8.19 — жёстче удержание чүкө внутри экрана

В версии 0.8.18 отдельные чүкө всё ещё иногда вылетали за край экрана. В 0.8.19 ограничение усилено ещё заметнее.

## Что изменено

- внешний невидимый периметр стал плотнее и ближе к краю видимой области;
- у стенок увеличено трение и почти убран отскок;
- ещё немного ослаблен дальний разлёт;
- существенно усилено торможение у края;
- добавлен жёсткий inward rebound: если чүкө доходят до самого внешнего радиуса, им принудительно задаётся скорость обратно внутрь.

## Ожидаемый эффект

- чүкө должны оставаться внутри экрана заметно надёжнее;
- разлёт останется, но станет компактнее;
- FPS должен сохраниться.
