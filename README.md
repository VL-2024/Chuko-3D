# CHUKO Modern 3D v0.8.16 — restored scatter with tighter pre-impact release

В v0.8.15 кучка иногда вообще не разлеталась: она удерживалась слишком долго, и к моменту реального контакта Havok не всегда успевал нормально включить динамику.

## Что изменено

- Кучка теперь отпускается немного раньше перед контактом.
- Допуск по горизонтальному совпадению с точкой удара расширен, чтобы разблокировка не пропускалась.
- Добавлен защитный fallback: если САКА уже вошла в зону удара, а кучка ещё зафиксирована, она принудительно разблокируется в этот же кадр.
- Немного усилен, но всё ещё умеренный impact boost, чтобы разлёт снова был живым.

## Ожидаемый эффект

- кучка не должна заметно расходиться заранее;
- разлёт должен снова появиться;
- точка удара должна оставаться близкой к маркеру.
