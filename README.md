# CHUKO Modern 3D v0.8.14 — точная точка падения

Исправлена неточность между жёлтым маркером и фактическим местом контакта САКА.

## Что изменено

- Маркер теперь трактуется как **точка фактического контакта с кучкой**, а не как математическая точка центра САКА на уровне поля.
- И превью траектории, и реальный бросок используют одну контактную высоту.
- На последнем участке снижения Havok сохраняет вертикальное движение и вращение, но X/Z скорость мягко корректируется так, чтобы САКА пришла точно к выбранному маркеру.
- Коррекция работает только в последние доли секунды и не является телепортом.
- Механика плотной кучки и текущий разлёт v0.8.13 сохранены.

## Проверка

Сделайте несколько ручных бросков в левую, центральную и правую часть кучки и сравните жёлтое кольцо с фактической точкой первого контакта.
