# CHUKO Modern 3D v0.9.1 — GLB integration

Первый билд со штатными 3D-ассетами вместо временных процедурных моделей. Основа механики — стабильная v0.8.22.

## Подключены модели

- `assets/models/Chuko_4435_Meshy_mobile.glb` — 12 чүкө;
- `assets/models/Khan_quad_mobile.glb` — ХАН;
- `assets/models/Saka_3118_mobile_2K_1K.glb` — САКА.

## Важная архитектура

GLB используются **только как визуальные модели**. Проверенная Havok-физика v0.8.22 остаётся на прежних невидимых proxy-мешах. Это позволяет менять внешний вид, не ломая баллистику, контакт и разлёт.

Чүкө загружается один раз, а затем клонируется для 12 игровых объектов с общими геометрией, материалом и текстурами.

## Настройка

В `⚙ НАСТРОЙКА` добавлен блок `GLB МОДЕЛИ`:
- размер GLB чүкө;
- высота GLB чүкө;
- размер/высота ХАН;
- размер/высота САКА.

Это нужно только для первого точного совмещения реальных моделей с уже настроенной физикой.

## Проверить на iPhone

1. Все ли три GLB появились и правильно текстурированы.
2. Размер и посадку чүкө относительно круга.
3. Размер ХАН и САКА.
4. Полёт САКА и разлёт должны быть такими же, как в v0.8.22.
5. FPS.
