# CHUKO Modern 3D v0.8.9 — кучка уменьшена ещё сильнее

В эту версию заложены ваши последние параметры, но стартовая кучка сделана ещё компактнее, чтобы все чүкө лучше помещались внутри круга.

## Что изменено

- уменьшен параметр `chukoScale`;
- сужена кучка по ширине (`spreadX`);
- уменьшена глубина кучки (`spreadZ`);
- слегка скорректирован центр кучки по `pileZ`.

## Текущая базовая идея

Экран остаётся максимально близким к 20.61:
- фон и поле — из исходных файлов;
- поверх них — 3D-чүкө, ХАН и САКА;
- панель настройки остаётся, чтобы вы могли при желании ещё на 1–2 шага докрутить размер и посадку.
