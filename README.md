# CHUKO Modern 3D v0.12.2

Исправлена геометрия итогового разлёта.

## Белая линия — единственная граница результата
Выбитые чүкө теперь получают конечные точки сразу за белым кругом:
- достаточно далеко, чтобы модель не касалась белой линии;
- но не у внешнего зелёного края ковра.

## Чүкө внутри
- распределяются по всему кругу;
- добавлен минимальный интервал между конечными точками;
- убраны плотные кучки из нескольких чүкө;
- часть чүкө может лежать у самой белой линии и немного перекрывать её краем, при этом центр остаётся внутри.

## Выбитые чүкө
Направления теперь строятся широким веером относительно реальной точки удара САКА:
- первый — по направлению удара;
- следующие чередуются вправо/влево всё шире;
- поэтому 3–5 выбитых не должны улетать одной плотной группой в одну сторону.

## САКА
Сохранена привязка точки падения к реальному ближайшему чүкө: в момент контакта САКА должна касаться хотя бы одного чүкө.
