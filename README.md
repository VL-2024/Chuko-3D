# CHUKO Modern 3D v0.11.1 — strict scenario visualization

Исправлено главное замечание v0.11.0: визуальный разлёт теперь должен строго соответствовать сценарию.

## Что теперь считается «выбито»

Белая линия на поле — игровая граница.

В v0.11.0 результат технически определялся по положению **центра** модели относительно радиуса 2.22. Из-за размера самого чүкө его край мог визуально оказаться за белой линией, хотя центр ещё считался внутри.

В v0.11.1 используется принцип из v20.61:

- LMS/DEMO заранее задаёт сценарий;
- сценарий заранее выбирает конкретные чүкө, которые должны быть выбиты;
- **нецелевые** чүкө удерживаются заметно внутри белой линии;
- **целевые** чүкө физически летят наружу;
- когда целевой чүкө достигает внешнего контрольного радиуса, он получает состояние `OUT` и фиксируется снаружи;
- если физике не хватило энергии, к концу анимации целевой чүкө гарантированно выводится наружу;
- при ZERO снаружи не должно остаться ни одного чүкө;
- при ONE — ровно 1;
- TWO — ровно 2;
- THREE — ровно 3;
- FOUR — ровно 4;
- FIVE — ровно 5;
- FIVE_KHAN — ровно 5 обычных + ХАН.

## Контрольные зоны

- белая игровая линия: `resultRadius = 2.22`;
- безопасная зона нецелевых: `scenarioInRadius = 1.84`;
- целевой считается визуально выбитым после `scenarioMarkOutRadius = 2.48`;
- финально фиксируется снаружи примерно на `scenarioOutRadius = 2.58`.

То есть теперь «слегка пересёк линию краем» не считается отдельным выбитым чүкө — визуально результат должен быть однозначным.

## LMS

Денежный результат (`win`) по-прежнему приходит только от LMS. 3D-движок визуализирует выданный LMS сценарий.
