# CHUKO Modern 3D v0.8.5 — field moved up, pieces reduced

В этой версии исправлены замечания по посадке на 2D-поле из v20.61.

## Что изменено

- Поле `field-realistic.webp` поднято выше на экране.
- Поле чуть уменьшено, чтобы круг лучше читался в портретном режиме.
- Чүкө и ХАН уменьшены.
- САКА тоже немного уменьшена, чтобы не спорить с полем.
- Стартовая кучка стала компактнее и лучше подогнана под внутренний круг поля.
- Центр кучки немного скорректирован под новый уровень поля.

## Что проверить

1. Совпадает ли теперь кучка с кругом поля.
2. Достаточно ли высоко поднято поле.
3. Нормален ли размер чүкө/ХАН/САКА.
4. FPS до броска, при ударе и после `ЕЩЁ БРОСОК`.
