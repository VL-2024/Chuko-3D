# CHUKO Modern 3D v0.11.4

Исправление визуального соответствия сценарию.

Что исправлено:
- в конце раунда обычные чүкө и ХАН один раз приводятся к корректному положению относительно видимой белой линии на поле;
- для ZERO/ONE/TWO/... картинка теперь должна соответствовать сценарию: нецелевые элементы внутри круга, целевые — снаружи;
- после этой однократной коррекции физика сразу замораживается, поэтому объекты больше не должны «оживать» после остановки;
- обычные чүкө остаются уменьшенными (чтение настроек сохранено).

Логика: сценарий задаёт итоговый визуальный результат, а не только текст на карточке.
