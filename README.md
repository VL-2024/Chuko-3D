# CHUKO Modern 3D v0.8.15 — точная точка контакта

Исправлена причина, по которой САКА иногда визуально попадала не туда, куда показывало кольцо.

## Что было

В v0.8.14 расчётная высота точки контакта была `0.54`. Для текущего размера чүкө/САКА это выше реальной зоны столкновения. САКА проходила нужные X/Z на этой высоте, продолжала снижаться и к реальному удару успевала немного сместиться.

## Что изменено

- реальная контактная плоскость снижена до `0.34`;
- последние доли полёта X/Z-скорость рассчитывается так, чтобы центр САКА пришёл точно в выбранную точку именно на этой высоте;
- кучка разблокируется только когда САКА уже выровнена с выбранной X/Z-точкой;
- жёлтое кольцо остаётся видимым во время полёта и исчезает при контакте — удобно проверять совпадение;
- разлёт и сила удара из v0.8.14 сохранены.
