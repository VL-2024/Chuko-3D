# CHUKO Modern 3D v0.8.17 — разлёт ограничен экраном

По вашему замечанию в этой версии я ограничил дальность разлёта чүкө, чтобы они не вылетали за границы экрана.

## Что изменено

- Добавлен невидимый внешний периметр вокруг игровой зоны.
- Смягчён контактный `impactBoost`:
  - ниже радиальный импульс;
  - ниже подъём вверх;
  - меньше случайный боковой разброс.
- Немного увеличено трение поля/страхующего пола.
- Добавлено мягкое торможение чүкө у внешнего края, чтобы они не уезжали слишком далеко.

## Ожидаемый эффект

- чүкө всё ещё живо разлетаются;
- но не должны уходить за пределы видимой области;
- FPS и текущая посадка сцены должны сохраниться.
