# CHUKO Modern 3D v0.11.0 — LMS + scenarios, phase 1

Стабильная 3D-база v0.10.3 сохранена. В этой версии добавлен первый слой полноценной лотерейной логики из архитектуры v20.61.

## Добавлено

- `lms-config.js` — runtime/LMS параметры;
- `lms-adapter.js` — сессия, баланс, новый билет, DEMO/REAL, iframe `postMessage`, mock QA;
- `src/scenario-config.js` — единый mapping сценариев;
- правильный цикл: **номинал → Новая игра/билет → бросок → результат → Новая игра**;
- баланс в UI;
- REAL и DEMO;
- LMS-authoritative `ticketId`, `scenario`, `win`, `balance`;
- визуальная привязка Havok-разлёта к сценарию;
- финальный fallback гарантирует, что визуально количество выбитых чүкө совпадает со сценарием.

## Сценарии

Для совместимости сохранены старые ID v20.61:

- `1 = ZERO`
- `2 = ONE`
- `3 = TWO`
- `4 = FIVE`
- `5 = FIVE_KHAN`

Добавлены:

- `6 = THREE`
- `7 = FOUR`

DEMO проходит их в логическом порядке: ZERO → ONE → TWO → THREE → FOUR → FIVE → FIVE_KHAN.

## Важно

В REAL денежный `win` не рассчитывается игрой. Его возвращает LMS. `demoMultiplier` применяется только в DEMO/MOCK для тестирования.

Следующий этап после проверки этой версии: автоигра, локальная история, Info, RU/KG и аудио.
