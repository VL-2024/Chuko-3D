# CHUKO Modern 3D v0.8.8 — полупрозрачная панель настройки

В этой версии панель настройки сделана более прозрачной, чтобы при открытых ползунках сразу видеть, как меняются поле, фон и кучка.

## Изменения

- панель `⚙ НАСТРОЙКА` стала полупрозрачной;
- уменьшена плотность затемнения;
- сохранён blur для читаемости текста;
- блоки внутри панели слегка отделены, чтобы параметры было удобно читать на фоне сцены.

Механика, ползунки и ваши текущие настройки по умолчанию не менялись.
