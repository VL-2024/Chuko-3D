# CHUKO Modern 3D v0.10.2

Исправления по замечаниям после v0.10.1.

## Что изменено

1. **САКА больше не должна уходить за белый круг**
- добавлено мягкое удержание САКА внутри белого игрового круга;
- если САКА всё же достигает границы, включается жёсткая защита и она возвращается внутрь;
- это убирает проваливание по краям, в том числе после вылета за белый круг.

2. **Исправлен дальний конец кучки**
- фактическая точка удара теперь ограничивается внутренней зоной контакта кучки;
- это предотвращает падение САКА за последнюю линию чүкө без контакта;
- немного увеличен допуск `pileReleaseHorizontalError`, чтобы динамика кучки отпускалась устойчивее.

3. **Что не менялось**
- Havok-физика в целом;
- ваши текущие модели GLB;
- счётчик выбитых чүкө из v0.10.1.
