# ЧҮКӨ Modern 3D — prototype v0.2

Второй мобильный прототип Babylon.js + Havok. За эталон ощущения и композиции берётся ЧҮКӨ v20.61. LMS по-прежнему не подключён.

## Что изменилось относительно v0.1

- Камера стала ближе к композиции v20.61: кучка лучше читается в центре поля.
- Кучка перестроена в компактную раскладку 4×3 по мотивам approved layout v20.61.
- ХАН теперь лежит внутри кучки, в центральном свободном месте.
- Простые бруски заменены временными low-poly формами с узкой серединой и асимметричными "суставами" — это всё ещё не финальные 3D-модели.
- САКА также получила временную неровную форму вместо чистой сферы; collision proxy остаётся сферой для стабильной мобильной физики.
- Дуга стала выше и длиннее: САКА стартует со стороны игрока, поднимается над полем и приходит в кучку с заметной вертикальной скоростью вниз.
- Масса САКА увеличена, restitution уменьшен, трение кучки снижено: контакт должен ощущаться жёстче, а чүкө — чаще переворачиваться и разлетаться без "резинового" отскока.
- Визуальный бортик поля стал ниже.
- Сохранены FPS / frame time / bodies / render scale и автоматическое снижение DPR при устойчивом падении FPS.

## Что тестируем в v0.2

1. Видна ли на телефоне именно высокая дуга, а не просто скольжение САКА к кучке.
2. Приходит ли САКА сверху в центр кучки.
3. Насколько естественно чүкө переворачиваются и разлетаются.
4. Не выскакивает ли ХАН сам по себе до контакта.
5. Сохраняются ли ~60 FPS на том же устройстве, где v0.1 показывала 60 FPS.

## Пока сознательно не делаем

- LMS / реальные билеты.
- Выигрышные сценарии и гарантированное количество выбитых чүкө.
- Финальные модели/текстуры чүкө, ХАН и САКА.
- Звуки, музыка, конфетти, автоигра.
- Production bundle / обфускацию.

## Запуск

Статический сайт, но Havok WASM и CDN лучше открывать через HTTP/HTTPS, а не `file://`.

```bash
python -m http.server 8080
```

Для GitHub Pages / Cloudflare Pages достаточно загрузить содержимое папки как обычный статический проект.
