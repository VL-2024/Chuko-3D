# CHUKO Modern 3D v0.8.12 — release по фактическому приближению САКА

Исправляет раннее расползание кучки из v0.8.11. Теперь момент разблокировки чүкө больше не рассчитывается по таймеру полёта.

## Что изменено

- После старта броска кучка остаётся STATIC.
- Каждый кадр проверяется фактическое положение САКА.
- Чүкө и ХАН переходят в динамику только когда САКА:
  - уже движется вниз;
  - находится почти над точкой попадания;
  - опустилась непосредственно к кучке.
- `impactBoost` также не включается до этого момента.

Так кучка не должна заметно шевелиться до фактического контакта, но сам Havok-удар и разлёт сохраняются.
