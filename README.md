# CHUKO Modern 3D v0.10.1

Исправлены два замечания после первого игрового цикла.

## 1. САКА больше не должна визуально проваливаться по краям
- базовый visual-only lift увеличен;
- дополнительный lift теперь зависит от расстояния от центра кучки по X/Z;
- это исправляет не только дальний край, но и левую/правую стороны;
- Havok-физика и баллистика не менялись.

## 2. Исправлен счётчик «Выбито»
- раньше результат сравнивался с радиусом 3.14 — фактически почти с внешней границей поля;
- при этом containment возвращал чүкө раньше, поэтому счётчик мог показывать 0;
- теперь результат считается относительно видимого белого игрового круга;
- установлен `game.resultRadius = 2.22`.

Проверьте несколько бросков в центр, влево и вправо.
