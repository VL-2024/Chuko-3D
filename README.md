# CHUKO Modern 3D v0.10.0 — game loop phase 1

Стабильная физика и визуал v0.9.11 сохранены. Начат следующий этап: собственно игровая логика.

## Добавлено
- режим **DEMO** (REAL пока отключён до LMS);
- выбор номинала **25 / 50 / 100 сом**;
- номер билета;
- кнопка **Новая игра**;
- игровой цикл: новая игра → бросок → ожидание физики → результат → новая игра;
- результат в DEMO считается по фактической физике:
  - сколько чүкө вышло за игровой круг;
  - вышел ли ХАН.

## Важно
Это пока не серверный сценарий и не финальная лотерейная логика. На следующем этапе можно добавить сценарный контроллер `ZERO / ONE / TWO / THREE / FOUR / FIVE / FIVE_KHAN`, а затем подключить LMS-адаптер.
