# CHUKO Modern 3D v0.8.1 — direct background from v20.61

Версия v0.8.1 делает ещё один шаг к визуалу ЧҮКӨ v20.61: теперь загруженная картинка `background-realistic.webp` используется как основной backplate почти 1-в-1, а игровое поле опирается на `field-clean.webp`. Механика, Havok-физика и FPS-оптимизации не менялись.

## Что изменено

- Фон из `background-realistic.webp` теперь используется как основной задник, крупнее и прямее, почти без художественной переработки.
- Добавлен мягкий нижний градиент для стыка фона с 3D-полем и для читаемости кучки/UI.
- Игровая поверхность теперь использует текстуру `field-clean.webp`, что визуально приближает поле к версии v20.61.
- Освещение слегка подстроено под тёплую закатную сцену из референса.

## Что не менялось

- 12 чүкө + ХАН + САКА.
- Прицеливание, дуга броска и разлёт.
- Havok CONVEX_HULL colliders.
- Pooling/reset и стабильность на iPhone.

## Что проверить

1. В шапке должна быть версия `v0.8.1`.
2. Насколько фон стал ближе к картинке из v20.61.
3. Насколько поле стало ближе к стилистике v20.61.
4. FPS до броска, во время удара и после `ЕЩЁ БРОСОК`.
