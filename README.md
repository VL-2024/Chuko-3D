# CHUKO Modern 3D v0.11.3 — stable scenario physics

Исправления после v0.11.2.

## Главное

### 1. Убрано повторное движение после остановки
В v0.11.2 сценарная коррекция могла через некоторое время снова задавать скорость или переносить уже остановившийся чүкө. Это полностью убрано.

Теперь:
- сценарий влияет на физику только в первые ~420 мс после контакта;
- никаких поздних телепортов/перестановок при показе результата нет;
- примерно через 1.10 сек физика раунда фиксируется, поэтому чүкө и САКА не могут «ожить» позже.

### 2. Сценарий задаётся в момент реального удара
- нужные чүкө выбираются среди тех, которые фактически ближе всего к точке контакта САКА;
- выбранные получают усиленный импульс сразу в момент удара;
- невыбранные получают намного меньший импульс и короткое раннее удержание внутри круга;
- после ранней фазы никакой сценарный код предметы уже не двигает.

### 3. Размер обычных чүкө = 0.60
- `chukoScale` по умолчанию теперь **0.60**;
- диапазон ползунка начинается с 0.50;
- этот параметр теперь масштабирует только 12 обычных чүкө; ХАН сохраняет свой отдельный размер.

### 4. Белый круг
Координаты белой линии скорректированы под текущий `field-realistic.webp`, а нецелевые элементы удерживаются с большим запасом внутри линии.

## Что проверить
1. ZERO: ни один обычный чүкө визуально не должен выйти из белого круга.
2. ONE/TWO/THREE: нужное число элементов должно вылетать сразу после удара, а не позже.
3. После остановки ни чүкө, ни ХАН, ни САКА больше не должны самопроизвольно сдвигаться.
