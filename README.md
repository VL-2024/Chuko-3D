# CHUKO Modern 3D v0.12.0 — deterministic scenario scatter

Полностью переделана логика сценарного разлёта.

## Новый принцип

Теперь игра сначала знает сценарий от LMS/DEMO, затем **до запуска САКА** рассчитывает конечные точки падения всех 12 чүкө и ХАНА. Только после этого начинается бросок.

- ZERO: все 12 конечных точек внутри белого круга;
- ONE: 11 внутри, 1 снаружи;
- TWO: 10 внутри, 2 снаружи;
- THREE: 9 внутри, 3 снаружи;
- FOUR: 8 внутри, 4 снаружи;
- FIVE: 7 внутри, 5 снаружи;
- FIVE_KHAN: 7 обычных внутри, 5 обычных снаружи + ХАН снаружи.

## Как идёт анимация

1. При отпускании САКА выбирается фактическая точка контакта.
2. До начала полёта выбираются конкретные целевые чүкө и для каждого элемента рассчитывается конечная точка.
3. САКА летит по прежней баллистике.
4. В момент контакта запускается единая непрерывная анимация разлёта от текущего положения к заранее рассчитанным точкам.
5. После приземления элементы сразу остаются на месте.
6. Никакой поздней коррекции раскладки и повторного движения после остановки больше нет.

Сценарные чүкө больше не управляются серией дополнительных физических импульсов после падения. Havok остаётся для полёта САКА и базовой сцены; сценарный разлёт визуализируется детерминированно.
