# CHUKO Modern 3D v0.9.8 — realistic dust

Пыль из v0.9.7 выглядела как расходящееся кольцо. В этой версии кольцевой эффект полностью убран.

## Что изменено

- удалено расширяющееся световое/пылевое кольцо;
- оставлен только короткий локальный contact flash;
- пыль теперь состоит из небольшого количества отдельных частиц;
- частицы расходятся несимметрично, низко над землёй;
- уменьшены размер, скорость и прозрачность частиц;
- увеличен разброс времени жизни для более естественного исчезновения;
- цвет пыли приближен к сухой земле поля.

## Что не менялось

- Havok-физика;
- траектория САКА;
- GLB-модели;
- фон, ковёр и пользовательские параметры сцены.

## Проверить

1. Пыль теперь должна выглядеть как небольшой неровный выброс, а не круг.
2. FPS должен остаться 60.
