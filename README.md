# CHUKO Modern 3D v0.9.11 — pileZ and SAKA visual lift fix

В этой версии внесены две адресные правки.

## Что изменено

1. **Кучка вперёд / назад**
- стартовое значение `pileZ` изменено с **-1.00** на **-1.20**.

2. **САКА больше не должна проваливаться на дальнем крае**
- исправлена логика синхронизации GLB-визуала САКА;
- раньше проверка шла по несуществующему `item.kind`, из-за чего визуальный lift фактически не применялся;
- теперь lift применяется правильно по `item.visual.kind === 'saka'`;
- добавлен небольшой **дополнительный lift на дальнем крае**, когда САКА уходит глубже за кучку.

## Прочее
- обновлён ключ localStorage, чтобы версия открывалась с новыми дефолтами сразу.
