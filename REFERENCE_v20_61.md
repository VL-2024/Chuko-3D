# CHUKO Modern 3D v0.11.3 reference

Сценарная логика больше не использует поздний force/teleport. Выбор целевых чүкө происходит в момент фактического контакта САКА, затем сценарий только кратковременно усиливает/ограничивает скорости в начальной фазе разлёта. Через ~1.10 сек тела фиксируются в текущих физических позициях.
