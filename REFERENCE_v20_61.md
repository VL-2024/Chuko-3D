# Механические ориентиры из ЧҮКӨ v20.61

Использовано как reference при создании prototype v0.1:

- `chukoCount = 12`
- `pileOffsetY = -28` — компактная кучка немного выше центра 2D-поля; в 3D перенесено как небольшой сдвиг кучки по Z.
- `sakaFlightArcHeight = 190` — в v20.61 делает видимую верхнюю дугу; в 3D заменено настоящей баллистикой Havok.
- `sakaAirborneNoCollision = true` — в 2D нужен был запрет бокового касания до точки приземления; в 3D больше не нужен, так как САКА физически летит над поверхностью.
- `impactBoost = 1.22`, `scatterSpeed = 7.2` и отдельные eject-параметры — пока не переносятся буквально: первый этап проверяет нативное столкновение Havok без сценарного принуждения.
- размеры 2D: regular 16, KHAN 19, SAKA 28 — относительное соотношение сохранено: KHAN чуть больше, SAKA заметно крупнее.

Важно: итог выигрыша в будущей Real-версии снова должен задаваться серверным сценарием, а Havok будет только визуализировать этот результат.
