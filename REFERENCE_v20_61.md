# ЧҮКӨ v20.61 -> Modern 3D v0.7 reference

Механическим эталоном остаётся 2D-версия v20.61. Modern 3D переносит её принципы в Babylon.js + Havok.

## Сохраняем из v20.61

- 12 чүкө и ХАН в компактной кучке.
- САКА крупнее обычного чүкө.
- Бросок идёт сверху по дуге в выбранную область кучки.
- Игрок управляет направлением и точкой попадания.
- Удар должен ощущаться тяжёлым и давать читаемый разлёт.
- Результат будущей Real-игры позже снова будет определяться сценарием/LMS, а не свободной физикой.

## Состояние v0.7

- Babylon.js + Havok стабильно работают на мобильном.
- CONVEX_HULL для чүкө, ХАНА и САКА.
- Pooling/reset без пересоздания Havok-тел.
- Процедурные organic low-poly чүкө вместо финальных GLB-моделей.
- Первый художественный слой: круглое поле, кыргызский орнамент, горный горизонт, небо и тёплый свет.
- Внешняя среда специально сделана дешёвой: без HDR, без тяжёлых текстур, без physics bodies и без теней на дальних объектах.

Следующий шаг после проверки FPS — либо корректировка v0.7.x, либо переход к финальным оптимизированным 3D-моделям чүкө/ХАН/САКА и более точному художественному оформлению.
