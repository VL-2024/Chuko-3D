# CHUKO Modern 3D v0.12.3 reference

Главная ось детерминированного разлёта теперь направлена от точки контакта САКА через центр кучки и дальше. Видимый прицел привязывается к реальному чүкө до броска, а разлёт запускается только в узкой зоне фактического контакта. OUT-точки находятся за зелёным ковром при сохранении их видимости на экране.
